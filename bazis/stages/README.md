# Этапы пайплайна ТЗ → БАЗИС

Каждый этап — отдельная папка с инструкцией. **Не смешивать** с `docs/` — там только расчёты конкретных проектов (`*_DIMENSIONS.md`).

| № | Этап | Папка | Когда |
|---|------|-------|-------|
| 1 | ТЗ → JSON | `prompts/`, `INSTRUCT.md` | Чертеж/спецификация → расчёт габаритов и `placement` |
| 2 | Проверка схемы | `schema/` | JSON соответствует `furniture.schema.json` |
| 3 | **Проверка геометрии** | **`stages/placement_check/`** | После расчёта координат; **выполняет AI**: `python main.py finish …` |
| 4 | Импорт | `basis_scripts/` | Скрипт + JSON в БАЗИС-Мебельщик |

Расчёты по конкретному изделию (таблицы placement, формулы) — в `docs/<project>_DIMENSIONS.md`.
