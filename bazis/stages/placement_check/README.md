# Этап 3: проверка placement (пересечения панелей)



**Когда:** JSON уже заполнен, все `placement` посчитаны по ТЗ.  

**До:** импорт в БАЗИС (`basis_scripts/ImportFurnitureFromJSON.js`).  

**Код:** `src/geometry_check.py`, `src/finish_project.py`.



## Зачем



Ошибки координат дают наложение деталей в модели: полка насквозь через перегородку, две полки в одном ярусе. Проверка ищет пересечения объёмов (AABB в ГСК `basis_mebelshik`).



---



## Для пользователя



**Вам ничего запускать не нужно.** После расчёта JSON агент Cursor сам выполняет этап 3 и сообщает результат: OK, что автоисправлено, что требует решения по ТЗ.



---



## Для AI-агента



После каждого создания или правки `examples/<project>.json`:



```bash

python main.py finish examples/<project>.json

```



Команда автоматически:



1. `validate` — схема;

2. `check-geometry` — пересечения корпуса;

3. разрез горизонталей вокруг стоек, если нужно;

4. сохранение JSON;

5. копия в `basis_scripts/<project>.json`.



При ошибках — исправить JSON и повторить. Не просить пользователя запускать CLI.



Подробнее: [AGENTS.md](../../AGENTS.md).

---

## Типовые ошибки из практики

- **“Верх открыт, а двери на всю высоту”**: если по виду изделия верхний ярус открыт (полка делит корпус), фасады (`door_front`) должны закрывать только нижний проём — верхняя зона остаётся открытой.
- **“Ручек нет в модели”**: ручки ставятся только на фасады `type: door_front`/`drawer_front` при `hardware.handles.count > 0`. Важно `type` и `placement`, а не конкретное имя панели.

---

## Правила разрешения



| Пересечение | Действие |

|-------------|----------|

| Горизонталь ↔ вертикаль (один ярус Y) | `finish` режет полку по X |

| Горизонталь ↔ горизонталь | Ошибка расчёта — правка в JSON |

| Вертикаль ↔ вертикаль | **Не дробить** без указания в ТЗ |

| Фасады (`door_front`, `front_panel`) | В проверку не входят |



**Приоритет:** стойки и боковины цельные; полки можно делить.



---



## Низкоуровневые команды (только отладка)



`validate`, `check-geometry` — для разработки, не для пользователя.



---



## Ограничения



- Проверяются только **корпусные** панели (без фасадов).

- Стык задника и угол X+Z (шов ≤20 мм) не считаются ошибкой.

- Только bounding box — без пазов и фрезеровок.

- После авторазделения полок агент обновляет `docs/<project>_DIMENSIONS.md`.



Порог: `--min-overlap-volume 1.0` (мм³).
