# Инструкции для AI-агента (bazis-json-converter)

## Главное

Пользователь **не запускает** CLI проверок вручную. Агент делает это **сам** после каждого создания или правки мебельного JSON.

## Когда запускать

После любого из действий:

- новый `examples/<project>.json` по ТЗ;
- изменение `panels[]`, `placement`, габаритов;
- правка координат в `docs/*_DIMENSIONS.md`, если менялся JSON.

## Одна команда — весь этап 3

Из корня проекта (venv):

```bash
python main.py finish examples/<project>.json
```

Команда автоматически:

1. проверяет JSON по схеме;
2. ищет пересечения корпусных панелей;
3. режет горизонтали вокруг стоек, если нужно;
4. сохраняет исправленный JSON;
5. копирует в `basis_scripts/<project>.json` (если файл в `examples/`).

## Если `finish` не прошёл

| Проблема | Действие агента |
|----------|-----------------|
| Ошибки схемы | Исправить JSON, снова `finish` |
| `split_horizontal_*` после автофикса | Доработать placement / разделить полки в JSON |
| `adjust_vertical_or_merge` | Не дробить стойки; править координаты или объединить детали по ТЗ |
| Остались пересечения | Обновить `docs/<project>_DIMENSIONS.md`, повторить `finish` |

## Отчёт пользователю

Кратко сообщить результат `finish`: схема OK/нет, геометрия OK/нет, что автоисправлено, что требует ручного решения по ТЗ. **Не** скидывать пользователю список CLI-команд для ручного запуска.

## Порядок нового ТЗ

1. ТЗ → расчёт → JSON + `docs/<project>_DIMENSIONS.md`
2. **`python main.py finish examples/<project>.json`**
3. Импорт в БАЗИС (пользователь) → сверка с чертежом
