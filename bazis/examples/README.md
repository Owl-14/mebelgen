# `examples/` — эталонные JSON-проекты (исходники)

В этой папке лежат **валидные примеры проектов** по `schema/furniture.schema.json`.

Они используются для:

- ручной правки и развития формата,
- регрессионной проверки (`python main.py validate ...`),
- создания копий в `basis_scripts/` для импорта в БАЗИС.

## Список примеров

- `moderator_cabinet.json` — тумба модератора (сложный пример: ящики/дверь/полки).
- `kashpo.json` — кашпо 3000×500×1000, 5 секций, полка на 650.
- `cabinet_700x400x500.json` — простой шкафчик с 6 полками и 1 дверцей.
- `security_desk.json` — стойка охраны (пример нестандартного изделия).

## Правило

Каждое новое ТЗ → **новый** файл `examples/<project>.json` + свой расчёт `docs/<project>_DIMENSIONS.md`.
