# Расчёт тумбы под ТВ 1600×450×600 (2 двери + 2 ящика)

Источник: чертёж на изображении.

## Исходные данные

| Параметр | Значение |
|---|---|
| W | 1600 |
| H | 600 |
| Глубина столешницы | 450 |
| Глубина корпуса | 400 |
| Разбивка по X | 414 / 708 / 414 |
| Высота корпуса (внутри) | 430 |
| Цоколь | 114 |

## Принятые допущения (estimated)

- Толщина ЛДСП: **16** мм (по разбиению 1600 и сумме секций).
- Толщина столешницы: **40** мм, свес **50 мм вперёд** (чтобы получить 450 при корпусе 400).
- Задник: ДВП **3.2** мм.
- Полки в боковых секциях: по 1 шт. на уровне ~середины (для визуального соответствия).

## Корпус (по `TUMBA_RULES`)

Координаты в ГСК `basis_mebelshik`.

```
Цоколь (условно): y 0..114
Дно:    y 114..130, x 0..1600, z 0..396.8
Бока/перегородки: y 130..560, z 0..396.8
Крышка (столешница): y 560..600, x 0..1600, z -50..400
Задник: y 130..560, x 16..1584, z 396.8..400
```

### Разбивка по X (T=16)

```
Левый бок:        0..16
Левый отсек:      16..430  (414)
Перегородка 1:    430..446
Центр отсек:      446..1154 (708)
Перегородка 2:    1154..1170
Правый отсек:     1170..1584 (414)
Правый бок:       1584..1600
```

## Фасады (двери + ящики)

Зазор по фасадам: gap=2 мм.

### Двери (врезные в проём)

```
Y: 132..558 (высота 426)
Z: 0..16
```

| Дверь | x1..x2 |
|---|---|
| Левая | 18..428 |
| Правая | 1172..1582 |

### Фасады ящиков (2 шт., по фасадной полосе)

Центр проём: `446..1154`, фасад с зазором: `x 448..1152`.

| Ящик | y1..y2 |
|---|---|
| 1 | 132..344 |
| 2 | 346..558 |

Z фасада: `0..16`.

## Полки боковых секций

Полка (по 1 на секцию), принята: `y 345..361`, `z 0..396.8`.
