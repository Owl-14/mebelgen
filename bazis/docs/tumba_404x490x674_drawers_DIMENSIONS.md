# Расчёт тумбы 404×490×674 (3 ящика + верхняя ниша)

Источник: чертёж на изображении.

## Исходные данные

| Параметр | Значение |
|---|---|
| W × D × H | 404 × 490 × 674 |
| Верхняя ниша | H=117, ширина внутри 368 |
| Ящики | 3 шт. |
| Короб ящика (по схеме) | 311 × 444 × 81 |
| Толщина ЛДСП | принято 16 (нет в ТЗ) |
| Задник | ДВП 3.2 (принято) |
| Зазоры | gap=2 |

## Корпус (по `TUMBA_RULES`)

Принято \(T=16\).

```
Дно:     y 0..16,   x 0..404,   z 0..490
Крышка:  y 658..674, x 0..404,  z 0..490
Бок:     y 16..658, x 0..16 / 388..404, z 0..490
Задник:  y 16..658, x 16..388, z 486.8..490
```

Внутренняя ширина: \(W_{in} = 404 - 2×16 = 372\) мм.

## Ниша сверху и полка под нишей

По картинке: открытая ниша H=117 от низа крышки.

```
Y_низ_крышки = 658
Y_верх_полки_ниши = 658 - 117 = 541
Полка (T=16): y 539..555  (оставили 2 мм зазор до ниши)
```

Полка под нишей: `x 16..388`, `z 0..486.8`.

## Фасады 3 ящиков (по Y)

Фасадная зона: `y 68..539` (от боковины 16 + gap=2 → 18, и ещё технологический отступ до фасадов; принято 68 как безопасный старт для модели).

```
H_zone = 539 - 68 = 471
H_one ≈ (471 - 2*gap) / 3 ≈ 155.7
```

| Ящик | y1..y2 фасада |
|---|---|
| 1 | 68..224 |
| 2 | 226..382 |
| 3 | 384..539 |

Фасады (внутри проёма, чтобы не пересекать боковины): `x 18..386`, `z 0..16`.
