# `docs/` — расчёты, правила и эксплуатационные заметки

Здесь лежит документация по **конкретным проектам** и эксплуатации БАЗИС.

Проверка пересечений `placement` — отдельный этап пайплайна: **[stages/placement_check/README.md](../stages/placement_check/README.md)**.

## Файлы

- **`BASIS_AUTOMATION.md`**
  - как работает установка фурнитуры через скрипт (ручки/направляющие),
  - почему без базы поставщика часть фурнитуры не появляется,
  - что делать мастерами БАЗИС.

- **`CABINET_DIMENSIONS.md`**
  - расчёт и таблицы `placement` **только** для проекта “Тумба для модератора”.
  - это **образец формата**, не шаблон размеров.

- **`kashpo_DIMENSIONS.md`**
  - расчёт и placement для проекта “Кашпо”.

- **`cabinet_700x400x500_DIMENSIONS.md`**
  - расчёт и placement для проекта “Шкаф 700×400×500”.

- **`security_desk_DIMENSIONS.md`**
  - расчёт и placement для проекта “Стойка охраны”.

## Как добавлять новый проект

Для каждого нового ТЗ создаём свой файл:

- `docs/<project>_DIMENSIONS.md`

Он должен содержать:

- исходные данные ТЗ (W/D/H, T, опоры, секции),
- принятые допущения (что помечено `estimated`),
- таблицы `placement` основных деталей,
- формулы/проверки, чтобы быстро сверять по чертежу.
