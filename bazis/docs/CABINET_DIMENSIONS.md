# Расчёт тумбы модератора (по чертежу)

> **Только для проекта «Тумба для модератора».**  
> Для нового ТЗ — новый расчёт и файл `docs/<проект>_DIMENSIONS.md`.  
> См. [INSTRUCT.md](../INSTRUCT.md) §0 и §6.

T = 16 мм, опоры = 38 мм, габарит **1000 × 400 × 750**, зазор фасадов **2 мм**.

## Зазоры (почему элементы не должны упираться)

| Конфликт | Было | Стало |
|----------|------|--------|
| Полка в фасад | Z 0…400 | **Z 16…384** (фасады впереди, z=0…16) |
| Полка в заднюю | Z до 400 | **Z до 384** (задняя z=384…400) |
| Дверь в крышку | Y до 748 | **Y до 732** (низ крышки 734 − 2) |

Глубина полки: **384 − 16 = 368 мм**.

## placement

| Деталь | x1–x2 | y1–y2 | z1–z2 |
|--------|-------|-------|-------|
| Дно, крышка | 0–1000 | 38–54 / 734–750 | 0–400 |
| Боковины | 0–16 / 984–1000 | 54–734 | 0–400 |
| Перегородки | 349–365 / 635–651 | 54–734 | **16–384** |
| Задняя | 16–984 | 54–734 | 384–400 |
| Полки (средняя, правая) | по секции | 270–286 | **16–384** |
| **Дно ящика** (×3, левая секция) | 32–333 | 58/290/522 +16 | **20–370** |
| Фасады | по секции | см. ярусы | **0–16** |
| Дверь | 653–982 | **56–732** | 0–16 |

Корпус по Y: дно верх **54**, низ крышки **734**.  
Дверь: 54+2=**56** … 734−2=**732** (высота **676**).

Фасады ящиков (левая секция): та же полоса **56…732**, три фасада по **224 мм**, между ними **2 мм**:  
`56+(224+2)×0` … `280 | 282…506 | 508…732`.

Все `horizont`: **NewPanel(x2−x1, z2−z1)**. Привязка **GabMin** → (x1,y1,z1).
