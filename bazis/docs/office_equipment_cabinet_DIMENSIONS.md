# Расчёт тумбы для оргтехники 1200×(350/270)×740

> По ТЗ: **W×D×H = 1200×(350/270)×740** мм, цвет **орех**.  
> Принято: общая глубина изделия 350 (столешница), корпус глубина 270 стоит по передней кромке, задник 3.2 мм внутри. Свес столешницы 80 мм вперёд.

## Исходные данные (из картинки)

| Параметр | Значение |
|----------|----------|
| Габариты | 1200 × 350/270 × 740 |
| Каркас | ЛДСП 22 |
| Полки/фасады | ЛДСП 16 |
| Задняя стенка | ДВП 3.2, 1 сторона ламинирована |
| Кромка | ПВХ 2 |
| Перегородка | есть, 2 отсека |
| Полки | по 1 в каждом отсеке |
| Расстояния | в каждом отсеке одинаковые (2 проёма равные) |
| Нагрузка на полку | 30 кг |
| Ручка | скоба, межосевое 96, металл сатин |
| Ручка на двери | 50 мм от верхнего края |
| Петли | регулируемые |
| Угол открытия | 110 |
| Опоры | регулируемые (высота не задана) |

## Принятые допущения

- **D=350/270** трактуем как: столешница глубина 350, корпус (дно/стойки/полки) глубина 270 и расположен по **передней** кромке: \(z=0..270\).
- Задник ДВП 3.2 мм стоит по задней грани корпуса: \(z=270-3.2=266.8..270\).
- Зазор по фасадам: 2 мм по периметру и между дверями.

## Координаты корпуса (ГСК `basis_mebelshik`)

Обозначения:
- \(T_{carcass}=22\), \(T_{shelf}=16\), \(T_{back}=3.2\)
- \(z_{setback}=0\)
- Внутренняя ширина: \(W_{in} = 1200 - 2×22 = 1156\)

### Основные панели

```
Крышка (столешница): y 718..740, x 0..1200, z 0..350
Крышка (столешница): y 718..740, x 0..1200, z -80..270
Дно (корпус):        y 0..22,    x 0..1200, z 16..266.8
Боковина левая:      x 0..22,    y 22..718, z 16..266.8
Боковина правая:     x 1178..1200, y 22..718, z 16..266.8
Задник ДВП:          y 22..718, x 22..1178, z 266.8..270
```

### Перегородка (2 равных отсека)

```
Остаток по X внутри: 1156 - 22 = 1134
Каждый отсек:        1134/2 = 567
Перегородка: x1=22+567=589, x2=611, y 22..718, z 16..266.8
```

## Полки (по 1 на отсек, равные проёмы)

Внутренняя высота: \(H_{in}=740-22-22=696\).

Одна полка (T=16) делит на 2 равных проёма:

```
H_clear = (696 - 16) / 2 = 340
Полка: y1 = 22 + 340 = 362, y2 = 378
```

| Полка | x1..x2 | y1..y2 | z1..z2 |
|------|--------|--------|--------|
| Левая | 22..589 | 362..378 | 0..266.8 |
| Правая | 611..1178 | 362..378 | 0..266.8 |

## Двери (накладные, 2 шт., закрывают НИЖНИЙ проём)

```
Зазор 2 мм: слева/справа/между дверями/снизу, и 2 мм до полки (сверху двери).
Толщина двери 16 мм.
Двери стоят по передней кромке изделия: z 0..16.  
По X двери **внутри проёмов** с зазором 2 мм к боковине/перегородке.
```

| Дверь | x1..x2 | y1..y2 | z1..z2 |
|------|--------|--------|--------|
| Левая | 24..587 | 24..360 | 0..16 |
| Правая | 613..1176 | 24..360 | 0..16 |
