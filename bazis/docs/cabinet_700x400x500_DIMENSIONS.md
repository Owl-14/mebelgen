# Расчёт шкафа 700×400×500 (по запросу ТЗ)

> Отдельный проект. W×D×H = **700×400×500** мм, T=16, 6 полок, 1 дверь.

## Исходные данные

| Параметр | Значение |
|----------|----------|
| W × D × H | 700 × 400 × 500 |
| T | 16 мм |
| Полок | 6 (стационарные) |
| Дверь | 1 распашная, фасад спереди |
| Опоры | не заданы → дно с Y=0 (без цоколя) |

## Корпус (top_bottom_over_sides)

```
Дно:     y 0…16,    x 0…700,  z 0…400
Крышка:  y 484…500, x 0…700,  z 0…400
Боковины: x 0…16 / 684…700, y 16…484, z 0…400
Задняя:  x 16…684, y 16…484, z 384…400
```

Внутренняя высота проёма: **484 − 16 = 468** мм.

## 6 полок — равномерно

Между верхом дна и низом крышки **7 промежутков**, 6 полок по T=16:

```
H_зазор = (468 − 6×16) / 7 = (468 − 96) / 7 = 372/7 ≈ 53,14 → 53 мм
```

| № | y1 | y2 |
|---|-----|-----|
| 1 | 69 | 85 |
| 2 | 138 | 154 |
| 3 | 207 | 223 |
| 4 | 276 | 292 |
| 5 | 345 | 361 |
| 6 | 414 | 430 |

Полки: x 16…684, z 16…384 (глубина **368**).

Проверка: после полки 6 зазор до крышки 484−430=**54** мм ≈ 53.

## Дверь (зазор 2 мм)

```
x: 2…698  (ширина 696)
y: 18…482 (высота 464)
z: 0…16
```
