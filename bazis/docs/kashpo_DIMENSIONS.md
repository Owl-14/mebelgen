# Расчёт «Кашпо» (по ТЗ заказчика)

> Проект **отдельный** от тумбы модератора. Источник: ТЗ + чертёж (3000×500×1000, 5 секций, полка 650 мм).

## Исходные данные ТЗ

| Параметр | Значение |
|----------|----------|
| Габарит W×D×H | 3000 × 500 × 1000 мм |
| ЛДСП T | 16 мм |
| Цвет | Дуб Кендал H3170 |
| Секций по фронту | 5 (равные) |
| Полка под вкладную/горшки | **650 мм от пола** (низ полки Y=650) |
| Горшок (ТЗ) | 300×280×600 мм (H×W×L) |
| Опоры | регулируемые пластиковые |
| Количество изделий | 2 шт. |

## Принятые допущения (estimated)

| Параметр | Значение | Причина |
|----------|----------|---------|
| Hleg | **100 мм** | по виду бокового разреза на чертеже |
| Конструкция | top_bottom_over_sides | как в INSTRUCT |
| Нижние ниши | без фасадов (открыты) | по 3D и фронтальному виду |
| Верхняя зона | открытая «чаша» над полкой | под вкладную с горшками |
| z полок/перегородок | 16…484 | не пересекать заднюю 484…500 |

## Корпус (Hleg=100, T=16, H=1000)

```
Y дна низ/верх     = 100 … 116
Y боковин          = 116 … 984
Y крышки           = 984 … 1000
Полка (под горшки) = 650 … 666
```

## Ширина секций (5 равных)

```
Внутр между боковинами = 3000 - 32 = 2968
Минус 4 перегородки     = 2968 - 64 = 2904
Ширина секции           = 2904 / 5 = 580,8 мм
```

|--------|----|----|--------|

| 2 | 613 | 1194 | 581 |
| 3 | 1210 | 1791 | 581 |

Перегородки: 597–613, 1194–1210, 1791–1807, 2388–2404.

## Замечание по горшку

Глубина корпуса **500 мм**, в ТЗ длина горшка **600 мм** — не помещается по Z без уточнения (ориентация, другая вкладная, опечатка). В модели полка на полную глубину 484 мм.
