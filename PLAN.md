# MEBELGEN — генератор визуальных референсов мебели из ТЗ

Инструмент для проектировщиков мебели: на вход — техническое задание в формате
Word (`.doc`/`.docx`, таблица-спецификация), на выход — для каждого изделия
готовый лист-референс в стиле присланных образцов (`ME-RA`):
2D-чертежи с размерами + 3D-изометрия + выноски с материалами +
блок «Материалы и описание» + штамп (title block).

---

## 1. Что на входе и что на выходе

**Вход** (пример — `Кабинеты ДРЧК.doc`): таблица из 6 колонок
`№ | Наименование | Изображение | Технические характеристики | Ед.изм | Кол-во`.
В колонке характеристик — габариты `ШхГхВ`, материал (МДФ), цвет (RAL/NCS),
толщины деталей, фурнитура (замок, push-open, штанга, полки, ящики, латунь, цоколь).

**Выход** на каждое изделие:
- `<имя>.svg` — векторный лист A4 (всегда, без внешних зависимостей);
- `<имя>.png` и общий `specs.pdf` — растровая/печатная версия (если доступен экспортёр);
- `specs.json` — структурированные данные всех изделий (для интеграций).

Стиль листа повторяет образцы: белый фон, тонкая рамка, кремовый материал
с теневой раскраской граней, латунные акценты (золото), размерные линии со
стрелками и выносными линиями, выноски-аннотации, штамп `ME-RA` снизу справа,
список материалов снизу слева.

---

## 2. Почему параметрическая генерация, а не нейросеть / тяжёлый CAD

Образцы — это параметрическая корпусная мебель (коробки, цилиндры) с **точными
размерами**. Поэтому ядро — детерминированная параметрическая генерация
(SVG: ортогональные виды + изометрия). Это:
- даёт точные размеры на чертеже (главное требование «чертежи»);
- воспроизводимо и не зависит от платных API/GPU;
- легко расширяется новыми типами мебели.

Рассмотренные альтернативы и почему отклонены: FreeCAD/Blender headless — тяжело
и хрупко на Windows; генеративные image-модели — не дают точных размеров;
three.js + headless Chrome — возможно как опция для «фотореалистичного» 3D,
но изометрия в SVG проще, легче и соответствует подписи «3D ИЗОМЕТРИЯ» на образцах.

## 3. Структура проекта и назначение модулей

```
mebelgen/
  __init__.py
  cli.py                  # CLI: mebelgen generate <doc> --out output/
  config.py               # палитра цветов, шрифты, геометрия листа A4, карты RAL/NCS

  parsing/
    doc_reader.py         # .doc -> .docx (через MS Word/win32com), чтение таблицы (python-docx)
    spec_parser.py        # текст характеристик -> поля: габариты, материал, цвет, фичи

  model/
    spec.py               # dataclasses: Dimensions, Material, Feature, FurnitureSpec
    classifier.py         # имя+фичи -> архетип (wardrobe/desk/cabinet/coffee_*) + параметры

  geometry/
    iso.py                # изометрическая проекция (30°), хелперы точек/граней
    primitives.py         # параметрические примитивы: box (3 грани), cylinder, panel, disc
    views.py              # сборка ортогональных видов (front/side/top) из параметров

  archetypes/             # по модулю на тип мебели: строят виды + 3D + выноски
    base.py               # интерфейс Archetype: build_front/top/iso/callouts/dims
    wardrobe.py           # шкаф 2-дверный высокий (штанга/полки/обувь или 4 полки)
    cabinet.py            # тумба/шкаф низкий 2-дверный (полка, ручки/замок)
    desk_panel.py         # рабочий стол на боковых панелях + экран + латунные ножки
    drawer_unit.py        # тумба с ящиками + ниша (1100x450x750)
    coffee_round.py       # кофейный стол на цилиндре-пьедестале (Ø500)
    coffee_fluted.py      # кофейный стол — рифлёный цилиндр/флютинг (Ø400)
    coffee_rect.py        # журнальный/кофейный стол прямоугольный (1000x450x450, 400-куб)

  draw/
    svg.py                # лёгкий SVG-канвас (line/rect/poly/ellipse/text/group/defs)
    dimensions.py         # размерные линии: выносные линии, стрелки, текст размера
    callouts.py           # выноски: точка-цель + ломаная-лидер + подпись
    titleblock.py         # штамп ME-RA (лого, слоган, наименование+габариты, дата, рук.)
    materials.py          # блок «Материалы и описание» (буллеты)
    sheet.py              # компоновка листа A4: подписи видов, виды, штамп, материалы

  render/
    export.py             # SVG -> PNG/PDF (Playwright если есть; иначе только SVG)

output/                   # результаты (svg/png/pdf/json)
input_specs/              # исходные ТЗ и извлечённый текст
```

### Поток данных
`doc_reader` → строки таблицы → `spec_parser` → `FurnitureSpec` →
`classifier` → архетип+параметры → `archetypes/*` (виды+3D+размеры+выноски) →
`draw/sheet` (SVG-лист) → `render/export` (PNG/PDF). CLI связывает всё.

## 4. Ключевые элементы рендера (соответствие образцам)
- **Изометрия**: проекция `(x,y,z) -> (Ox+(x−y)·cos30, Oy+(x+y)·sin30 − z)`,
  три грани коробки с разной заливкой (верх светлее, бок темнее) + контур.
- **Размеры**: горизонтальные/вертикальные цепочки с засечками-стрелками,
  выносными линиями и текстом (мм подразумеваются).
- **Выноски**: маленькая точка на детали → ломаная → текст (материал/фурнитура).
- **Латунь**: золотые тонкие прямоугольники/линии по периметру (Т-профиль/вставки).
- **Штамп**: таблица снизу справа — `ME-RA`, «мебель.пространство.качество»,
  строка «<Наименование> ШхГхВ», «Дата», «Руководитель».

## 5. Этапы реализации
1. Каркас пакета + `config` + модель данных.
2. Парсер `.doc/.docx` → JSON (проверка на `Кабинеты ДРЧК`).
3. Парсер характеристик (размеры/цвет/фичи) + классификатор архетипов.
4. SVG-движок + размеры + выноски + штамп + блок материалов.
5. Геометрия (изометрия + ортовиды) и архетипы (от коробок к цилиндрам).
6. Компоновка листа A4 + экспорт PNG/PDF + CLI.
7. Прогон на реальном ТЗ, визуальная сверка с образцами, доводка.

---

## 6. Расширяемость
- Новый тип мебели = новый модуль в `archetypes/` + правило в `classifier`.
- Бренд/штамп/цвета — через `config.py` (легко сменить `ME-RA` на другой).
- Источник ТЗ — любой `.doc/.docx` с таблицей-спецификацией такого вида.
