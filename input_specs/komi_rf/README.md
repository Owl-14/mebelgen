# ТЗ-пример: офисная мебель для АО «Россельхозбанк» (Коми РФ)

Реальный заказ (Сыктывкар, 3-я часть). Набор примеров ТЗ для конвейера
`ТЗ → ParamSpec → генератор`. Покрывает широкий спектр архетипов: столы,
тумбы (приставные/подкатные), шкафы (документов/гардеробные/комбинированные),
встроенные системы, трибуна, кухни.

## Состав
- `tz_komi_rf.txt` — текст технического задания (извлечён из `source/tz_komi_rf.doc`
  через `antiword -m UTF-8.txt`).
- `zakaz_NF-447.xlsx` — заказ покупателя № НФ-447 от 30.12.2025 (спецификация позиций).
- `chertezhi/*.pdf` — 23 чертежа изделий с габаритами и узлами (детальное ТЗ на каждую позицию).
- `source/tz_komi_rf.doc` — исходный .doc (тяжёлый, в git не коммитится — см. `.gitignore`).

## Следующий шаг
## Разметка позиций (ParamSpec)

Спецификации сняты из текстового слоя чертежей (`pypdf`) — материал, декор-код
(Н 1399 ST 10 Дуб Денвер трюфель и др.), конфигурация секций, фурнитура.

**Размечено и валидно (`tools/basis/paramspecs/komi_*.json`, все проходят
schema+geometry+consistency):**

| Чертёж | ParamSpec | archetype |
|---|---|---|
| 46 Шкаф для документов 1000×400×1800 | `komi_46_shkaf_dokumenty` | cabinet (2 двери × 4 полки) |
| 47 Шкаф гардеробный 1000×400×1800 | `komi_47_shkaf_garderobny` | door_unit (штанга+полки) |
| 48 Шкаф комбинированный 1000×400×1817 | `komi_48_shkaf_kombinirovanny` | cabinet (документы + гардероб) |
| 39/45 Тумба приставная 1000×500×750 | `komi_39_tumba_pristavnaya` | cabinet (ящики/полки/дверца) |
| 53 Тумба переговорной 800×400×900 | `komi_53_tumba_peregovornaya` | door_unit |
| 59 Тумба президиум 900×300×800 | `komi_59_tumba_prezidium` | shelving (задник открыт) |
| 72 Тумба подкатная 400×450×580 | `komi_72_tumba_podkatnaya` | drawer_unit (колёса) |
| 41 Стол переговорный Ø1200×750 | `komi_41_stol_peregovorny_round` | round_table |

Прогон: `python main.py generate paramspecs/komi_46_shkaf_dokumenty.json` →
schema/geometry/consistency + `material_refs`. Материалы дозаполняет политика (AKD-76).

**Отложено (нужен доработанный генератор / вне панельного конвейера):**
- **Столы на металлокаркасе** (38 директора, 43 зам, 44 брифинг, 52 большой перег.,
  69 корреспонденция, 71 охранник): desk-генератор строит панельные опоры, а тут
  металлокаркас — нужен режим «столешница + экран, ноги металл».
- **Композитные системы** (50 гардеробные 4000, 55 референты 3118, зона референтов):
  archetype `composite` (`blocks[]`) — многомодульные, отдельной разметкой.
- **Кухни** (61, 62), **трибуна** (60), **доборы** (55), **столешница с обрамлением**
  (73): бытовая техника/спец-формы/добор — вне текущего панельного конвейера.
