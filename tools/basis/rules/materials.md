# Политика материалов и фурнитуры

Цель: из **одного ТЗ** должна собираться полная, готовая к производству модель —
без ручных дозаполнений. Что в ТЗ указано явно — берём как есть. Чего нет —
детерминированно дозаполняет `src/materials_policy.py` (`apply_material_policy`),
вызывается в `generate_from_paramspec` перед сборкой. Все допущения → в `warnings`.

## Дефолты (когда в ТЗ не указано)

| Слот | Правило по умолчанию |
|---|---|
| **Плита корпуса** | ЛДСП, толщина из ТЗ (иначе 16). Столешница стола — 25/38. |
| **Задняя стенка** | ДВП 3 мм (стандарт). ЛДСП 16 — если ТЗ требует (премиум/жёсткость). |
| **Кромка** | Видимые фасады/торцы — 2 мм ПВХ; скрытые — 0.4 мм. |
| **Цвет/декор** | Из ТЗ (или кода декора). Иначе дефолт «Белый» + warning «подтвердить». |
| **Декор фасадов** | `materials.facade_color`/`facade_color_code` — если в ТЗ у фасадов свой декор/материал. Не задан → как корпус. |
| **Артикулы базы** | `materials.board_article`/`facade_article` — точная позиция производственной базы (выбор в Studio или из ТЗ). Не задан → резолвер подбирает по декору+толщине. |
| **Ручки** | Есть фасады и не указано → ручка-скоба 128 мм, count = число фасадов. `push`/«без ручек» → без ручек. |
| **Направляющие** | Есть ящики → шариковые с доводчиком, длина по глубине (250…550, зазор −30). |
| **Петли** | Есть двери → накладные 110°. |
| **Опоры** | Подкатное изделие → 4 колёсные опоры. Иначе — как в ТЗ (высоту не форсируем: меняет геометрию). |

Политика **идемпотентна и недеструктивна**: заполняет только пустые поля, не
затирая явные значения из ТЗ, и не меняет геометрию, кроме толщины задника
(ДВП 3 мм по умолчанию — влияет на глубину полок и позицию задника).

## Привязка к реальной базе

После политики `materials.resolve_project_materials` сопоставляет выбор с
производственной базой (`materials/baza_materiala.json`) → `material_refs`:
плита/задник/кромка — одна позиция (по коду декора/цвету/толщине), фурнитура —
шорт-лист реальных кандидатов из группы. Слабое совпадение не подменяется —
`resolved:false` + кандидаты (артикул подтверждает технолог). CLI:
`python main.py materials --resolve project.json`.

## Границы

Точные `basisName`/артикулы БАЗИС (MatBase) сверяются при доступной лицензии
(AKD-12). Политика даёт производственно осмысленный дефолт + флаг допущения, а
не «молчаливую» подстановку.
