# Реверс правок производства: крепёж и его оформление в .b3d (эталон технолога)

Источник: `wardrobe_demo.b3d`, переделанный проектировщиком производства поверх
нашей облачной сборки (июль 2026). Извлечено `scripts/extract_b3d_hardware.py`.
Это **авторитетный производственный эталон**: здесь и логика расстановки, и то,
как крепёж технически оформлен в БАЗИСе. Шкаф-образец: 1200×600×2200, ЛДСП 16,
задник ХДФ 4 накладной, левая секция — дверь+полки, правая — 3 ящика+полки.

Все координаты: X ширина, Y высота (0 = пол), Z глубина (задник у 0, фронт 603.2).

## 1. Технический формат (как оформляет десктопный Мебельщик)

### 1.1 Библиотека крепежа — `Document.FurnList`

Каждый ТИП крепежа — запись `F<FastID>` (FastID — произвольный int-id):

```
F781660101:
  Name        = "Стяжка эксцентриковая (комплект эксцентрик+шток с пластиком саморез)\r11154, MNFX.d15x11.5.Z.34xd7.PL"
  FastID      = 781660101
  DatumMode   = 2|3         # база позиционирования (2 — ребро стыка, 3 — наружная пласть)
  ParamType   = 1|2|3|6     # 1 сквозной (конфирмат/саморез/гвоздь), 2 эксцентриковая
                            # стяжка, 3 шкант, 6 накол-разметка
  ParamOffset = 16.0        # толщина прошиваемой детали (16 ЛДСП, 4 ХДФ)
  Color, MinX..MaxZ         # габарит условного тела
  Holes: [ {X,Y,Z, DirX,DirY,DirZ, Radius, Depth, DrillMode} ]
```

**Ключевое:** шаблон крепежа — ДВУХДЕТАЛЬНЫЙ: одна запись несёт отверстия в
ОБЕ соединяемые детали, в локальной системе крепежа. Ось X — вдоль оси
соединения; плоскость стыка проходит через X=0 (ParamType 2) или X=ParamOffset
(ParamType 1/3 — вход сверла с наружной пласти первой детали). `DrillMode`:
СКВОЗНЫЕ проходы (конфирмат Ø8×16, гвоздь Ø3×4) — 1, ГЛУХИЕ крепёжные
(каналы, чашки, гнёзда, тела в ответной детали) — 2 (наши облачные болванки
писали 1 всюду).
Мешей (TriData) у крепежа НЕТ — только у декоративных изделий (ручки, опоры,
петля, штанга).

**Name = `<имя>\r<артикул>` ровно из нашей производственной базы**
(`materials/baza_materiala.json`): стяжка «11154, MNFX.d15x11.5.Z.34xd7.PL» 6₽,
конфирмат «3851, CNFM.7x50.H4» 3₽, шкант «651, SHCN.8x30mm.20000st» 0.6₽,
гвоздь «67», саморез «76», SE01PB 17₽ — резолвер может подбирать их напрямую.

### 1.2 Инстансы крепежа — `Model` → `Obj Type=3001`

```
Obj: Type=3001, Name=<как в библиотеке>, ID, Color,
     Trans {X,Y,Z, Rx,Ry,Rz,Rw},   # позиция точки привязки + кватернион
     FastID → запись FurnList
```

Кватернион ориентирует локальную ось X шаблона вдоль оси соединения.
Точка привязки: ParamType 1/3 — на НАРУЖНОЙ пласти первой детали (вход
сверла); ParamType 2 — на ребре «плоскость стыка × пласть, куда смотрит чашка».

### 1.3 Панели — `Obj Type=4002` и кромка Butts

```
Obj: Type=4002, Name, ArtPos, Trans{...},
     Mat   = "ЛДСП, 16 мм, Белый базовый, EggerW908 ST2"   # полная строка базы
     Thick = 16.0, Contour = blob (полилиния),
     Butts: [ {Mat="Кромка ПВХ, 19/2 мм (в цвет)...", Thick=2.0, Width=19.0,
               Elem=N, Sign="2х19(в цвет)", Overhung=30.0, Allowance=0.5} ]
```

**Кромка задаётся ПО СТОРОНАМ контура (Elem = индекс стороны), а не «на всю
деталь»**. Фактические правила технолога:

| Деталь | Кромка |
|---|---|
| Дверь, фасады ящиков | 2.0 мм на ВСЕХ 4 сторонах |
| Боковины, перегородка | 0.5 мм ТОЛЬКО передний торец |
| Крышка, дно | 0.5 мм перед + оба боковых торца (задний — без) |
| Полки | 0.5 мм только перед |
| Короб ящика (боковины) | 0.5 мм верх+перед+зад; задняя панель 2 стороны |
| Дно ящика, задник | без кромки |

(Скрытые торцы НЕ кромятся вовсе — а не 0.4, как делали мы.)

Прочие типы объектов: 1005 сборка (двери/ящики — вложенные Objs), 4004
комплект направляющих → 2×4001 (корпусный и ящичный полоз, каждый со своими
саморезами-инстансами), 4001 узел фурнитуры (фланец штангодержателя), 2004
профиль (труба штанги, Thickness = длина), 999 гнутая деталь.

## 2. Шаблоны крепежа (точные размеры отверстий)

### 2.1 Стяжка эксцентриковая MNFX d15 (арт. 11154) — ParamType 2, Datum 2 — ×40
```
канал  Ø8  гл.34  @(0,−8,0)  dir +X   → в тело детали Б вдоль оси соединения
чашка  Ø15 гл.12.5 @(35,0,0) dir −Y   → в ПЛАСТЬ детали Б, центр на 35 от стыка
шток   Ø5  гл.12  @(0,−8,0)  dir −X   → в тело детали А (ввинчивается шток)
```
### 2.2 Конфирмат 7×50 (арт. 3851) — ParamType 1, Datum 3 — ×12
```
проход Ø8 гл.16 @(0,0,0)  dir +X      → СКВОЗЬ первую деталь (толщина 16)
тело   Ø5 гл.35 @(16,0,0) dir +X      → в торец второй детали
```
### 2.3 Шкант 8×30 (арт. 651) — ParamType 3, Datum 3 — ×52
```
гнездо Ø8 гл.21 @(16,0,0) dir +X      → в торец детали Б (за плоскостью стыка)
гнездо Ø8 гл.11 @(16,0,0) dir −X      → в пласть детали А (глухое, НЕ сквозное)
```
### 2.4 Эксцентрик пластиковый Ø20 SE01PB (полки съёмные) — ParamType 2 — ×16
```
чашка Ø20 гл.13 @(10,0,0) dir −Y      → в НИЖНЮЮ пласть полки, центр 10 от торца
шток  Ø5  гл.12 @(0,−8,0) dir −X      → в стойку
```
### 2.5 Гвоздь 1×16 (арт. 67, задник) — ParamType 1, ParamOffset=4 — ×92
```
проход Ø3 гл.4  @(0,0,0) dir +X       → сквозь ХДФ 4 мм
тело   Ø1 гл.12 @(4,0,0) dir +X       → в торец стойки/дна/крышки
```
### 2.6 Петля 110° DTC Pivot-Star (арт. C81A676FB) — ×4, с мешем
```
чашка  Ø35 гл.12 @(0, 8.5, 0)  dir −X          # в дверь
наколы Ø3  гл.2  @(0, 14.5, ±24) dir −X        # саморезы чашки
планка Ø3  гл.2  @(37, 0, ±16) dir −Y          # ответная планка: 37 от фронта,
                                               # наколы ±16 вдоль глубины
```
### 2.7 Саморез US3.5×16 (арт. 76, направляющие) — накол Ø3 гл.2 — ×27
### 2.8 Винт М4×16 (ручки) — Ø5 гл.16 сквозь фасад изнутри — ×8

## 3. Логика расстановки (правила технолога)

Стойки = боковины + перегородка. Схема корпуса top_bottom_over_sides
(дно/крышка перекрывают стойки), задник НАКЛАДНОЙ.

1. **Дно ↔ стойки: КОНФИРМАТЫ снизу** (голова в нижней пласти дна — не видна).
   По 2 на стойку, X = центр стойки, Z = **96 мм от заднего и переднего торца**.
   Рядом ШКАНТ на **+32 мм внутрь** от каждого конфирмата (вход тоже с нижней
   пласти дна): пара «конфирмат + шкант» с шагом 32.
2. **Крышка ↔ стойки: эксцентриковые стяжки MNFX** (чашка в ПЛАСТИ стойки на
   35 мм ниже стыка, смотрит внутрь секции; канал 34 вниз в торец стойки; шток
   вверх в крышку). По 2 на стойку, Z = 96 от торцов + шканты на 32 внутрь
   (вход шканта с ВЕРХНЕЙ пласти крышки, X = центр стойки).
3. **Стационарная полка ↔ стойка: стяжки MNFX** — канал в торец полки, чашка
   в НИЖНЕЙ пласти полки на 35 от торца, шток в стойку. 2 шт на сторону,
   Z = 96 от торцов корпуса; шканты на 32 внутрь (вход с наружной пласти
   стойки, глухое гнездо 11 в стойке + 21 в торце полки).
4. **Съёмные полки: эксцентрик Ø20 SE01PB вместо полкодержателей** — чашка в
   нижней пласти полки на 10 от торца, шток Ø5 в стойке. По 2 на сторону,
   отступы ≈65–70 от переднего/заднего края полки (факт: 67 сзади, 64 спереди).
   Полки утоплены от фронта на 16.
5. **Задник ХДФ 4 мм, накладной: гвозди 1×16 с шагом 96**. Позиция — наружная
   пласть задника, бой в ЦЕНТР торца (X=центр стойки; Y=центр дна/крышки).
   По стойкам: от Y=120 до 2136 шаг 96 (22 шт на стойку 2200). По дну (Y=68)
   и крышке (Y=2192): от X=32 шаг 96, последний подтянут к краю.
6. **Направляющие: шариковые полного выдвижения L500 «1045-20»** (глубина 600).
   Каждый полоз крепится **3 саморезами US3.5×16** в штатные монтажные
   отверстия: 37, 101 и 389 мм от переднего конца полоза; полоз заподлицо с
   фронтом корпуса; высота осей — низ ящика +16. Оформление: Obj 4004
   (комплект) → 2 × Obj 4001 (корпусный и ящичный полоз) с инстансами
   саморезов внутри.
7. **Петли: 4 шт на дверь H≈2200** (не 5, как наша формула >2000→5!).
   Уровни: **160 от низа, 100 от верха**, промежуточные равномерно (шаг ≈645).
   Ответная планка на 37 от фронта (наше значение совпало). Отверстия — по
   шаблону петли (чашка + наколы саморезов и планки Ø3×2 — производство
   размечает саморезы наколами, не сверлит Ø5).
8. **Ручки: 2 винта М4×16, сверлятся СКВОЗЬ фасад изнутри** (вход с задней
   пласти). Межцентровое 128.
9. **Опоры: 50×50 мм от углов дна** (4 шт, арт. 1127).
10. **Штанга**: труба-профиль D25 (Type 2004, длина 574 на секцию 576+зазор),
    фланцы-штангодержатели по бокам, разметка — накол «3x2»; верх фланца
    на ~1919 (полка над штангой 1900+).

## 4. Отличия от нашей текущей генерации (что менять)

| Узел | У нас (hardware.py) | У производства |
|---|---|---|
| Дно↔стойки | шкант+минификс по сетке 32 от торца | конфирмат снизу ×2 (96 от торцов) + шкант +32 |
| Крышка↔стойки | шкант+минификс | стяжка MNFX (чашка в стойке, 35 от стыка) ×2 + шкант |
| Съёмная полка | полкодержатель Ø8×10 | эксцентрик Ø20 SE01PB (чашка в полке) |
| Отступ крепежа от торцов | 32 | **96**, шкант парно на +32 |
| Задник | врезной, «гвозди по месту» | накладной ХДФ 4, гвозди шаг 96 в центры торцов |
| Петли на дверь 2200 | 5 | **4** (160 снизу / 100 сверху) |
| Присадка петли | планки Ø5×12 | наколы Ø3×2 (чашка Ø35×12 та же) |
| Направляющие | 3 винта Ø5 перед/центр/зад | 3 самореза в точки 37/101/389 от фронта |
| Кромка скрытых торцов | 0.4 всюду | **без кромки**; видимые не-фасадные 0.5 |
| Кромка, оформление | одно значение на деталь | по сторонам контура (Butts/Elem) |
| DrillMode отверстий | 1 | **2** (крепёжные) |

Примечание к памяти «система 32 — без конфирматов»: производство конфирматы
ПРИМЕНЯЕТ — но только снизу дна, где голова не видна. Шаг присадки 32
подтверждён (пары стяжка/конфирмат + шкант через 32), «96» = 3×32 ✓.

## 5. Статус внедрения (AKD-287, реализовано в compute_drilling)

Внедрено и сверено с эталоном по инвариантам (все совпали):

- дно — конфирматы снизу + шканты; крышка/стационарные полки — стяжки MNFX
  (чашка 35 от стыка) + шканты; отступы 96, шкант через 32 от стяжки;
- съёмные полки — SE01PB (чашка Ø20 на 10 от торца, 64 от торцов полки);
- гвозди задника: пары прокол Ø3 + тело Ø1×12, шаг 96, в центры торцов;
- петли: 4 на 2200 (160/100), чашка 22.5 от кромки + наколы ±24,
  планка — наколы Ø3×2 на 37 от фронта ±16;
- направляющие: наколы Ø3×2 в точки 37/101/389 (корпусный полоз) и
  37/192/224 (ящичный полоз) от переднего торца;
- кромка: фасады 2 по кругу, видимые не-фасадные 0.5, скрытые — без.

Осознанные отклонения от файла технолога:

- ящичный полоз крепим С ОБЕИХ сторон короба (36 наколов на 3 ящика против 27
  в эталоне — технолог разметил ящичную часть только с одной стороны);
- тонкий задник (ДВП/ХДФ ≤ 6 мм) по умолчанию накладной (`apply_back_mount`,
  AKD-179): лежит за корпусом, на 1 мм внутрь от его габарита (1198×2138 на
  1200×2140), а перегородки и полки при этом идут до задней плоскости
  корпуса — как у технолога (раньше они заканчивались на толщину задника
  раньше боковин, и гвоздям в перегородку было не во что бить);
- гвозди задника — только в стойки, перегородки, дно и крышку (92 у эталона);
  полки к заднику не прибиваются;
- кромка по сторонам контура сверена с файлом технолога: у горизонтальных
  деталей (`Elem=0` — передний торец) старая карта `_BUTT_SIDES` клала кромку
  на задний торец; фасады — 2 мм по кругу даже если ТЗ несёт «0.4»;
- полка над стеком ящиков садится в зону фасадов (верх полки = верх стека +
  зазор), верхний фасад заканчивается на зазор ниже её верха — фасады
  получаются равными (эталон: 3×208 при зазоре 4, полка 680..696);
- задняя стенка ящика — плита корпуса, не материал задника (раньше `.cfrn`
  выбирал материал по имени «задн…»);
- подпись материала панели в `.b3d`: «ЛДСП, 16 мм, Белый<CR>W1000 ST26» /
  «ХДФ, 4 мм» — форма базы десктопного Мебельщика;
- **короб ящика — конструкция технолога** (по умолчанию для всех ящиков,
  `columns.drawer_stack` / `drawer_unit`): боковины на всю глубину короба,
  задняя стенка МЕЖДУ боковинами у заднего торца (`box_back_mode: outside` —
  старая накладная), дно МЕЖДУ боковинами заподлицо с их низом и до задней
  стенки, передней стенки нет — её роль играет фасад. Умолчания: зазор
  направляющей 13 от пласти корпуса (`GUIDE_GAP`, слот 568 → короб 550),
  низ короба на 32 выше низа фасада (`BOX_Y_OFFSET`), боковина = фасад − 64
  (`BOX_HEIGHT_MARGIN`), глубина = самая длинная стандартная направляющая
  250…600, помещающаяся с запасом 100 до задника (`std_guide_length`);
- крепёж короба (`hardware.py`, «Короб ящика по эталону технолога»): каждый
  стык «торец → пласть» — стяжка MNFX (чашка Ø15×12.5 в пласти торцевой детали
  на 35 от торца, канал Ø8×34 в торец, шток Ø5×12 в ответную пласть) + шкант
  8×30 (21/11): дно↔боковины — по 2 на 96 от переднего/заднего края дна,
  шканты на 32 внутрь, чашки в нижней пласти дна; дно↔фасад — 2 на 96 от
  боковин, чашки на 35 от переднего торца; боковина↔фасад и боковина↔задняя —
  чашка на 96 от низа короба, шкант на 64 (стык ≥232 — как у корпуса);
  дно↔задняя — 2 конфирмата сквозь заднюю стенку (голова снаружи, под
  задником корпуса) + шканты. Итог на шкаф-эталон: 40 стяжек, 52 шканта,
  12 конфирматов — 1:1 с файлом технолога;
- фасад ящика: зазор `gaps.facade` с обеих сторон от края корпуса/центра
  перегородки (596 на колонну 600; дверь соседней секции заканчивается на
  полузазоре от центра перегородки — между ними 3 мм, как у технолога);
- штангодержатель: один накол Ø3×2 по оси штанги в стойку с каждой стороны
  (эталон «3x2»), винты — по месту через фланец;
- оси направляющих — низ короба + 32 (эталон: наколы на 126 при низе 94);
- сознательное отклонение: ящичный и корпусный полозья размечаем с ОБЕИХ
  сторон (36 наколов на 3 ящика против 27 в файле — технолог разметил один
  корпусный и один ящичный полоз на ящик, второй парой пропущен).
- разница общих количеств стяжек/шкантов с эталоном — от ДОБАВЛЕННЫХ технологом
  стационарных полок-разделителей между ящиками (другая конструкция изделия,
  не другая раскладка);
- `drillMode` в .cfrn — по эталону: сквозные проходы (конфирмат Ø8×16, прокол
  гвоздя, винт ручки, замок) — 1, глухие крепёжные — 2. Подтверждено платным
  round-trip (task 13311, tumba_moderatora_v3.b3d): режимы доезжают 1:1.

Верификация: `scripts/extract_b3d_hardware.py` (мировые отверстия эталона) +
инвариант-сравнение в истории AKD-287.
