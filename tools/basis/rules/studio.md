# BAZIS Studio: локальный редактор-предпросмотр (AKD-94…97)

Правки единицы мебели ДО платной прогонки через облако (~10₽/сборка).
«Функционал БАЗИСа, который нам нужен» не копируется в JS — браузер шлёт ParamSpec,
Python-конвейер возвращает готовую модель. **Один источник правды**: генераторы,
материалы, присадки, фурнитура и проверки — те же модули, что собирают `.b3d`.

Запуск: `python main.py studio <paramspec.json> [--port 8765] [--out <dir>]`

## Архитектура

- `src/studio.py`: HTTP-сервер на stdlib (без зависимостей), порт 8765;
- `GET /` — страница редактора (three.js, как webviewer: правосторонняя, Y-вверх);
- `POST /api/generate` — ParamSpec → `{viewer{panels,holes,hardware}, issues, stats, bom}`;
- `POST /api/techview` — чертёж SVG (фронт+бок);
- `POST /api/save` — ParamSpec в исходный файл + `<имя>.project.json`;
- `POST /api/export-cfrn` — бесплатный `.cfrn`;
- `POST /api/build-b3d` — платная сборка; **отклоняется (409), если проверки красные**.

## Редактор

- поля: габариты W/D/H, декор (цвет+код), толщина плиты, опоры, зазор;
- секции: тип (drawers/shelves/door/open), число ящиков/полок/дверей, доля ширины,
  добавление/удаление; raw-JSON редактор для остальных полей спеки;
- debounce 400 мс → живой пересчёт: 3D (панели+присадки+фурнитура), счётчики,
  BOM, чертёж; при ошибке схемы модель не сбрасывается — краснеет бейдж;
- бейджи проверок: схема / встык (consistency) / геометрия / .cfrn / присадки;
- кнопка «Собрать .b3d (~10₽)» активна ТОЛЬКО при зелёных проверках + confirm.

## Гарантии

- случайная трата на облако невозможна: клиентская блокировка + серверный отказ 409;
- сохранённый ParamSpec совместим с остальным конвейером (deliver/viewer/build-b3d);
- интерактивность покрыта тестом payload-на-правку (`tests/test_studio.py`) и
  проверена headless-браузером (правка поля → пересчёт → блокировка платной кнопки).
