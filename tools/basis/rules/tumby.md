# Правила для тумб/тумбочек

Применять, только если в ТЗ явно «тумба/тумбочка/тумба под …». Для стоек,
кашпо, стеллажей, шкафов-купе — **не** включать (строить общий корпус по
[core.md](core.md) §1–3). Базовые координаты/зазоры — там же.

- **Стек ящиков**: никаких стационарных перемычек между ярусами. Каждый ящик —
  отдельный короб: дно, 2 боковины, задняя, фасад. Ярус `k` привязан к своей
  паре `y1_k..y2_k` из фасадной полосы (core §3).
- **Короб ящика** (внутр. ширина секции `Sw`): дно `x = X_внутр..+Sw`; боковины
  по краям толщиной `T`; задняя смещена назад под направляющие. Варианты
  конструкции (дно между/под боковинами, задняя за/внутри) — см.
  [generators.md](generators.md), параметры короба.
- **Дверь поверх нижнего проёма**: если полка делит корпус на открытый верх и
  закрытый низ, `door_front` закрывает только низ — `y2_door = y1_полки - gap`.
- **Врезные двери в проём**: по X `x1 = T+gap .. x2 = X_перегородки-gap`.
- **Две глубины** (ТЗ вида `D_полн/D_корпус`, напр. 350/270): корпус
  `z 0..D_корпус-T_back`, задник за ним, столешница — со свесом вперёд
  (`top_overhang`, `depth_carcass`).
- **Верхняя ниша**: `open_top` — полка-отбивка + открытое пространство до крышки.
