# Правила построения модели для БАЗИС

Разнесены по файлам в [rules/](rules/):

| Файл | Содержание |
|---|---|
| [rules/core.md](rules/core.md) | Координаты, корпус, зазоры, фасадная полоса, колонки, фурнитура, рабочий процесс — **общее для всех архетипов** |
| [rules/tumby.md](rules/tumby.md) | Специфика тумб/тумбочек (стек ящиков, двери, ниша, две глубины) |
| [rules/generators.md](rules/generators.md) | Какие поля ParamSpec понимает каждый генератор (`src/generators/`) |

Одно правило важнее всех: **каждое ТЗ считается заново**. Между проектами
переносится только метод (координаты, формулы, типы деталей, формат JSON) —
никогда не сами `placement` из чужого проекта. Координаты считает генератор по
этим правилам, а не LLM; LLM выдаёт высокоуровневый `ParamSpec`.
