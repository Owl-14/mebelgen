# Akeda Studio — брендовые изображения

`akeda-studio-wordmark.png` и `akeda-studio-mark.png` — не нарисованные заново
варианты. Это два детерминированных crop исходного JPEG, который пользователь
передал 2026-08-04 для верхней левой марки Studio.

Параметры исходника: `1080 × 1080 px`, JPEG. Применена только операция crop и
перекодирование результата в PNG через системный `sips`:

```bash
sips -c 84 520 --cropOffset 550 284 -s format png <source.jpg> \
  --out akeda-studio-wordmark.png
sips -c 98 216 --cropOffset 460 452 -s format png <source.jpg> \
  --out akeda-studio-mark.png
```

Исходный квадрат не хранится в репозитории: в нём более 85% пустого белого поля.
Derivative-файлы сохраняют исходные пиксели леттеринга и знака; их нельзя
перерисовывать, трассировать, генерировать или заменять похожим шрифтом без новой
прямой просьбы пользователя.
