# Akeda Studio — эталонный локальный Review

Связанная задача: `MEB-093`.

Базовый SHA: `a0748256d78f9e910c1cfa7225c12d8ff4ddfa96`.
Дата фиксации: 2026-08-11.

Это не новая версия интерфейса. Здесь собран воспроизводимый снимок настоящего
Studio, с которым должны сравниваться следующие UX-срезы. В исходниках при
съёмке не менялись `src/studio.py`, `src/webviewer.py`, генераторы, ParamSpec,
материалы или API.

## Как воспроизвести

```bash
cd tools/basis
python main.py studio paramspecs/tumba_moderatora.json \
  --port 44180 --out /tmp/akeda-meb-093-review --no-open
```

Открыть `http://127.0.0.1:44180/`, в селекторе проекта выбрать «Тумба для
модератора». Не сохранять правки, сделанные только ради сценария проверки.

## Матрица действий и сценарии

| Область | Действие | Как проверить в живом Studio | Ожидаемый факт |
|---|---|---|---|
| Проект | Выбор изделия | Селектор «Изделие» | Перезагружаются 3D, проверки, сводка и формы выбранного проекта |
| Проект | Новое, переименование, копия | Кнопки под селектором | Открывается штатный сценарий, без потери текущего проекта до подтверждения |
| Проект | Каталог | «Каталог» | Открывается отдельный workspace без параметров последнего изделия |
| Проект | Ссылка согласования | «Создать ссылку на просмотр» | Открывается штатный безопасный сценарий создания ссылки |
| Проверки | Шесть инженерных статусов | «Состояние модели» | Видны схема, встык, геометрия, `.cfrn`, присадки, сверловка и база |
| Проверки | Автоисправление | При проблеме «Запустить автоисправление» | Не запускается без явного действия пользователя; причина остаётся видимой |
| Выбор | Выбрать/снять деталь | Клик по панели / `Esc` | Подсветка и карточка соответствуют одной детали; без выбора карточка не остаётся |
| Выбор | Точечные действия | «Изменить словами», «Чертёж» в карточке | Команда и деталировка адресованы выбранной детали |
| 3D | Ракурс | Аксон, перспектива, сверху, спереди, слева | Меняется камера настоящего `MebelScene` |
| 3D | Навигация | Drag, колесо, Shift+drag | Вращение/масштаб/перемещение работают без смены модели |
| 3D | Технические слои | Присадки, фурнитура, текстура, размеры, прозрачность | Каждый слой меняет реальную сцену, а не декоративную копию |
| 3D | Анимации | Клик по фасаду; «Открыть всё» / «Закрыть всё» | Створки и ящики анимируются; возврат восстанавливает закрытый вид |
| 3D | Exploded | Слайдер «Разбор» до 100 и обратно к 0 | Детали раздвигаются и возвращаются без изменения ParamSpec |
| Режимы | 3D, чертёж, раскрой | Вкладки в центре | Проект и выбранная деталь не теряются без причины; печать доступна только в подходящем режиме |
| Правая панель | Параметры, комплектация, производство, ссылки | Rail или вкладки панели | Каждый режим открывает именно свою область; скрытый режим не перехватывает фокус |
| Правки | Изменение поля | Поменять ширину, не сохраняя | Низ: `changed` → `recalculating` → актуальное/blocked/decision либо `stale` |
| Ошибка | Невалидный размер | Временно ввести `0` в «Ширина», ничего не сохранять | Низ сообщает о прежней модели и ошибке; производство не выдаётся за готовое |
| AI | Контекст/вложение/Undo | Composer внизу | Команда явно относится ко всему изделию либо выбранной детали; busy/error не скрывают историю |
| Производство | Save, `.cfrn`, `.b3d`, delivery, версии | Вкладка «Производство» | Гейт не разрешает устаревшую/блокирующую редакцию; платный `.b3d` не запускать во время QA |

## Проверка размеров

- `1280×720`: левая панель 300 px, центр 650 px, правая 330 px; верхние
  вкладки и HUD не пересекаются.
- `1440×900`: левая 300 px, центр 810 px, правая 330 px.
- `1920×1080`: левая 340 px, центр 1220 px, правая 360 px.

## Что ещё нужно проверить глазами перед закрытием MEB-093

1. В 3D покрутить, приблизить и отдалить модель; кликнуть по фасаду, затем
   выбрать другую внутреннюю панель.
2. Открыть фасады по одному, затем «Открыть всё» и «Закрыть всё»; вернуть
   разбор с 100 % в 0 %.
3. По очереди включить/выключить все пять слоёв и все пять ракурсов.
4. Перейти 3D → чертёж → раскрой → 3D; в чертеже выбрать деталь и убедиться,
   что в Studio сохранился корректный контекст.
5. На 1280 px и 1920 px убедиться, что ни HUD, ни composer, ни панели не
   перекрывают сцену и друг друга.
6. Проверить, что после временной невалидной правки статус честно пишет про
   предыдущую модель; затем перезагрузить страницу, не сохраняя тестовую правку.
