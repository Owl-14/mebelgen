# Akeda Studio — инспектор секций

Статус: `HYPOTHESIS / LOCAL REVIEW`
Задача: `MEB-096`, первый вертикальный срез
Дата: 2026-08-11

## Проблема

Сейчас каждая секция в правой панели одновременно показывает ящики, полки,
двери, ниши и точные уровни. Проектировщик видит поля, которые не относятся к
выбранному типу секции, и вынужден каждый раз перечитывать длинную форму.

## Граница среза

Меняется только представление существующего `SPEC.sections` в Studio:

- не меняются ParamSpec, API, генераторы, расчёты и `src/webviewer.py`;
- не меняются данные секции и действующие `data-i` / `data-k` обработчики;
- выбранная деталь остаётся в левой контекстной карточке: это отдельный
  утверждённый поток MEB-095, не дублируемый справа.

## Предлагаемая структура

```text
Секции

⌄ Секция 1 · Ящики · 33% ширины
  Тип                 [ Ящики        ]       Удалить
  Доля ширины         [ 0,33          ]
  Количество ящиков   [ 3             ]
  Высоты ящиков       [ 180, 180, 240 ]
  Фасадная зона       [ низ ] — [ верх ]

› Секция 2 · Открытая · 34% ширины
› Секция 3 · Дверь · 33% ширины

Добавить секцию
```

Каждая строка — настоящий HTML `details`, а не карточка или новая модель
данных. Сводка показывает порядковый номер, понятный тип и ширину. Внутри
открыты только поля, релевантные этому типу:

| Тип | Поля в раскрытии |
|---|---|
| Ящики | количество, высоты, границы фасадной зоны |
| Полки | количество, уровни полок |
| Дверь | количество дверей, границы фасадной зоны |
| Открытая | только тип и доля ширины |

## Состояния

- Первая секция открыта при первом входе; раскрытые пользователем секции не
  закрываются при локальном пересчёте.
- Удаление явно подписано и требует существующего безопасного пути удаления.
- При работе AI и точечной правке controls получают существующую блокировку,
  но summary остаётся читаемой.
- Если сумма высот ящиков больше высоты изделия, строка показывает реальное
  предупреждение существующей проверки; состояние не маскируется визуалом.

## Критерии review

- Для любого типа нет нерелевантных полей.
- Все действующие значения редактируемы и по-прежнему запускают обычный
  пересчёт.
- Секция не выглядит как отдельная web-карточка: одна поверхность, тонкие
  разделители, плотная инженерная сетка.
- 3D-модель, камеры, выбор, чат и предыдущая карточка детали не изменены.
