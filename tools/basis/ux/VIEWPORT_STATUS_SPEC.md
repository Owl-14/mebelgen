# Akeda Studio — нижняя строка состояния viewport

Статус: `APPROVED / LOCAL`

Задача: `MEB-098`, второй срез
Дата: 2026-08-04

## Назначение

Строка отвечает на три коротких инженерных вопроса:

1. Текущая ревизия изделия уже пересчитана и показана в 3D или ещё нет?
2. Какая деталь сейчас выбрана?
3. Какое действие доступно в текущем режиме?

Это не строка ответа AI. Этап команды, результат, Undo и журнал остаются в
AI-composer и левой истории операций.

## Компоновка

Постоянная плоская полоса высотой `24 px` проходит по нижней границе `#main`.
Она имеет непрозрачный белый фон и только верхнюю линию, без скругления, тени,
blur или glass-эффекта.

Слева направо:

- маркер и текст состояния модели;
- `Выбрано · <имя детали>` — только при реальном выборе;
- контекстная подсказка активного режима;
- фиксированные единицы `мм`.

Только состояние модели является `aria-live`. Выбор и подсказки не озвучиваются
при каждом клике, чтобы не создавать речевой шум.

## Реальные состояния модели

| Фаза | Полный текст | Смысл |
|---|---|---|
| `loading` | `Загружаю модель…` | первый запуск или открытие изделия |
| `pending` | `Изменения ожидают пересчёта…` | `SPEC` изменён, debounce ещё не запустил generate |
| `busy` | `Пересчитываю модель и проверки…` | активен актуальный `/api/generate` |
| `ready` | `Модель актуальна` | текущий ответ содержит viewer и прошёл проверки |
| `warning` | `Модель пересчитана · N ошибок` | текущий viewer показан, но проверки не пройдены |
| `no-viewer` | `Модель не обновлена · N ошибок` | новый viewer не получен, на canvas остаётся прошлый |
| `network` | `Не удалось пересчитать · показана предыдущая модель` | запрос/обработка завершились исключением |
| `draft` | `Черновик · модель ещё не построена` | пустое изделие до генерации |

Поздний ответ старого request ID не имеет права менять строку. `schedule()`
немедленно переводит модель в `pending`, а `apply()` принимает финальное
состояние только при совпадении request ID и JSON-ревизии `SPEC`.

## Контекстные подсказки

- 3D без выбора: `Клик — выбрать · перетаскивание — вращать · колесо — масштаб`;
- 3D с выбором: `Shift + перетаскивание — переместить · Esc — снять выбор`;
- чертёж: `Клик по детали — выбрать`;
- раскрой: `Раскрой текущей модели`.

Координаты курсора не показываются: реального cursor-coordinate API сейчас нет.

## Геометрия и адаптивность

- AI-composer поднят над status bar на `10 px`;
- toast остаётся ровно на `10 px` выше динамической высоты composer;
- чертёж получает динамический нижний padding, поэтому его можно прокрутить выше
  composer даже при длинном тексте и вложениях;
- status bar имеет `pointer-events:none` и не блокирует canvas;
- при ширине центра меньше `1000 px` используется короткий текст состояния;
- меньше `700 px` скрывается подсказка, но состояние, выбор и `мм` сохраняются;
- при критической ошибке/пересчёте на узкой ширине выбор уступает место состоянию.

## Связанные контракты

- SVG чертежа/раскроя привязан к `mode + request ID + JSON SPEC`; старая ревизия
  не разрешает печать;
- переименование изделия запускает пересчёт, потому что имя участвует в
  некоторых правилах генерации;
- динамическая высота composer синхронизируется сразу при росте текста и
  изменении вложений;
- `src/webviewer.py` и все внутренности `MebelScene` остаются неизменными.
