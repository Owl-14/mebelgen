# Akeda Studio — режимы правой панели

Статус: `APPROVED`
Дата: 2026-08-04

## Задача среза

Правая панель перестаёт быть единым документом на несколько экранов. Все
существующие поля, данные и действия распределяются между тремя рабочими
режимами. Переключение режима не меняет `SPEC`, не запускает генерацию и не
открывается автоматически при выборе детали.

Пользователь этого среза — проектировщик мебельного производства. Его задача в
панели — быстро выбрать один уровень решения: изменить конструкцию, проверить
комплектацию либо подготовить результат к передаче.

## Визуальный план

Палитра продолжает утверждённый язык Studio:

- `instrument-ink` — `#1a1d21`;
- `instrument-muted` — `#687180`;
- `instrument-line` — `#dfe3e8`;
- `instrument-surface` — `#ffffff`;
- `instrument-canvas` — `#f4f6f8`;
- `selection-blue` — `#3b82f6`.

Типографика: `Segoe UI` для интерфейса и `Consolas` только для raw ParamSpec и
точных инженерных данных. Заголовок группы — `12 px semibold`, подписи —
`11–12 px`, числа — с табличным начертанием.

```text
┌──────────────────────────────────────┐
│ Параметры изделия                 ‹  │
├────────────┬──────────────┬──────────┤
│ Параметры  │ Комплектация │ Производ.│
╞════════════╧══════════════╧══════════╡
│ Габариты                            │
│ Ширина                   [ 1000 ]    │
│ Глубина                  [  400 ]    │
│ ───────────────────────────────────  │
│ Материал                            │
│ …                                    │
└──────────────────────────────────────┘
```

Характерный элемент — плоская инструментальная рейка из трёх реальных этапов,
а не набор навигационных pills. Активный этап отмечает нижняя линия выбора.
Внутри остаётся одна белая поверхность; группы разделяются hairline-линиями,
без карточных рамок, теней, blur и декоративных эффектов.

Первый вариант с набором одинаковых fieldset-карточек отклонён: он выглядел бы
как типовая web-форма и не объяснял бы производственную последовательность.

## Карта режимов

| Режим | Существующие секции |
|---|---|
| Параметры | габариты, материал, опоры и зазор, архетип, параметры архетипа, секции, инженерный raw ParamSpec |
| Комплектация | фурнитура и параметры ручек, закупочная смета, BOM |
| Производство | сохранение, версии, `.cfrn`, лист согласования, `.b3d`, история сборок |

Raw ParamSpec находится внизу `Параметров` как закрытый инженерный раздел: он
редактирует весь `SPEC`, поэтому не относится к BOM или экспорту.

## Поведение

- collapsed rail сразу открывает выбранный режим;
- в открытой панели режим меняется табом без закрытия и без длинного scroll;
- активный режим хранится отдельно от решения `open / collapsed`;
- каждый режим сохраняет свой `scrollTop` до перезагрузки;
- скрытые panel имеют `hidden + inert`, но продолжают получать свежие данные от
  `fillForm()`, `paint()`, `renderHwSlots()` и `renderEstimate()`;
- при AI- или точечной мутации блокируется только содержимое режимов; вкладки и
  сворачивание панели остаются доступны;
- смена режима не вызывает `scene3d.resize()`: resize нужен только при реальном
  изменении ширины центрального viewport.

## Keyboard и ARIA

- открытая рейка: `Left / Right`, `Home / End`;
- collapsed rail: `Up / Down`, `Home / End`, штатные `Enter / Space` кнопки;
- открытие из rail переводит фокус на соответствующий tab;
- сворачивание возвращает фокус к rail-кнопке текущего режима;
- только активный tab имеет `aria-selected=true` и `tabindex=0`;
- только активный `tabpanel` доступен в tab order;
- `aria-expanded=true` получает только rail-кнопка открытого текущего режима.

## Неприкосновенные контракты

- все прежние ID полей и действий сохранены в единственном экземпляре;
- обычный выбор детали не открывает правую панель;
- live-правки параметров, секции, база декоров, фурнитура, смета, BOM, версии,
  Save, CFRN, delivery и зелёный гейт B3D работают прежними обработчиками;
- платная B3D-сборка не запускается во время UI review;
- `src/webviewer.py`, `MebelScene`, модель, камеры и физика не изменяются.

## Review checklist

- [x] при открытии виден только один из трёх режимов;
- [x] режимы переключаются и из rail, и из открытой панели;
- [x] смена режима не пересчитывает модель и не сбрасывает введённые значения;
- [x] все прежние параметры доступны ровно в одном месте;
- [x] смета и BOM обновляются, пока режим скрыт;
- [x] B3D остаётся заблокирован при красных проверках и не запускается в review;
- [x] open/collapsed и фокус работают на ширинах панели `300 / 330 / 360 px`;
- [x] нижний composer, status bar и 3D не меняют поведение.
