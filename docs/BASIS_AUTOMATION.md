# Автоматизация: от JSON до раскроя и чертежей (БАЗИС 2026)

Цель системы: **ТЗ заказчика → JSON → импорт → готовая модель** с фурнитурой и документацией.

## Что уже делает скрипт `ImportFurnitureFromJSON.js`

| Этап | Источник в JSON | Результат в БАЗИС |
|------|-----------------|-------------------|
| Корпус и детали | `panels[]` + `placement` | Панели ЛДСП на месте |
| Ручки | `hardware.handles` | 4× фурнитура на фасадах |
| Направляющие | `hardware.drawer_guides` + `drawers[]` | 6× установка (3 ящика × лев/прав стык) |

Версия БАЗИС: **2026.5.6.0 (64-bit)** — подходит API фурнитуры (`Mount`, `Mount1`, `Choose`).

## Первичная настройка фурнитуры (один раз на проект)

В JSON два поля с пустой строкой:

```json
"hardware": {
  "handles": { "furniture_encoded": "" },
  "drawer_guides": { "furniture_encoded": "" }
}
```

При импорте скрипт по очереди попросит:

1. **Ручку** — профильная, 128 мм, чёрная (как в ТЗ).
2. **Направляющую** — шариковые с доводчиком, ~350 мм.

После выбора скрипт покажет **длинную строку** — вставьте её в соответствующее поле `furniture_encoded`.

Альтернатива: указать путь к файлу фурнитуры в каталоге БАЗИС:

```json
"furniture_file": "C:\\...\\Catalog\\Guide350.f3d"
```

(точный путь зависит от вашей установки)

## Порядок работы в БАЗИС

1. Скопировать `ImportFurnitureFromJSON.js` → `Документы\BazisN\Scripts`.
2. Запустить скрипт, указать `moderator_cabinet.json`.
3. При первом запуске — выбрать ручку и направляющую, сохранить строки в JSON.
4. Повторный импорт — всё ставится автоматически.

## Частая ошибка: “ручки не появились”

Причины бывают две:

- в JSON `hardware.handles.count = 0` (скрипт вообще пропустит ручки);
- фасады не распознаны как панели `type: door_front` / `drawer_front` (скрипту некуда ставить ручку).

Проверка простая: в `panels[]` должны быть фасады с корректным `placement` и `basis_orientation: front`.  
При первом импорте скрипт попросит выбрать ручку в каталоге (если `furniture_encoded` пустой).

## Что нужно для «полного проекта по ТЗ»

| Задача | Сейчас | Следующий шаг |
|--------|--------|----------------|
| Геометрия корпуса | JSON + скрипт | — |
| Ящики (короб) | JSON + скрипт | — |
| Направляющие | JSON + Mount | при необходимости — отдельные encoded для лев/прав |
| Ручки | JSON + Mount1 | — |
| Петли двери | в JSON `doors[]`, не в скрипте | добавить `hardware.hinges` |
| Замки | в JSON `locks[]` | добавить установку замков |
| Кромка на панелях | в JSON `edge_banding` | дописать скрипт (назначение кромки) |
| Материал из базы | частично | выбрать материал U 740 в модели |
| **Карта раскроя** | в БАЗИС после модели | меню раскроя по деталировке |
| **Чертежи** | в БАЗИС после модели | отчёты / чертежи |
| **Присадка** | после фурнитуры | анализ модели в БАЗИС |

Без **материала + кромки + фурнитуры** раскрой будет по размерам, но без полной технологичности.

## Направляющие — как ставятся (важно)

Между **боковиной корпуса** (x=0…16) и **боковиной ящика** (x=32…48) есть зазор **16 мм** — панели **не стыкуются**.  
Поэтому `Mount(панель1, панель2)` **не создаёт объект** (в структуре модели пусто, хотя выбор в каталоге был).

Скрипт ставит направляющие так:

1. **`MountBox`** — в объём ящика (между боковинами ящика по `placement`).
2. Если не вышло — **`Mount1`** на грань корпуса (внутренняя) и на грань ящика (наружная), **отдельный экземпляр** фурнитуры на каждую установку.

### Нельзя подставлять «ручку-кнопку»

Ручка в каталоге монтируется только на **плоскость фасада** (`Mount1` на front).  
Для ящика нужна фурнитура **«направляющая»** / **«шариковая»** с типом монтажа **секция (box)** или **параллельные грани**.

Если в конце импорта: `Направляющие (успешных установок): 0` — выбрана не та фурнитура.

## Мастер «Установка ящиков» (BoxesMaker)

В API есть `NewBoxesMaker().Setup(...)` — штатный мастер БАЗИС, который создаёт ящик **целиком** с направляющими.

Мы **не используем** его в текущем импорте, потому что короб ящика уже задан в JSON. Иначе получится дублирование деталей.

## Дорожная карта системы

1. **Конвертер** (Python + Vision): чертёж/фото → JSON по схеме.
2. **Валидация** JSON по `furniture.schema.json`.
3. **Импорт БАЗИС** (текущий скрипт): панели + фурнитура.
4. **Расширения скрипта**: кромка, петли, замки, опоры.
5. **Шаблон отчётов** в БАЗИС: деталировка + раскрой + сборочный чертёж.
