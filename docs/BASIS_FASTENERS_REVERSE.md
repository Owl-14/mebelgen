# Реверс крепежа из готовых изделий БАЗИС (веб-вьювер, GLB)

Источник: реальные изделия заказчика на viewer.bazissoft.ru (2026-07-02).
API: `GET https://viewer.bazissoft.ru/api-viewer/models/<guid>` → метаданные
(name, size, `downloadLink` → GLB с материалами, `viewerV2.modelId`).
GLB = glTF 2.0: JSON-чанк содержит полную иерархию сборки с ИМЕНАМИ узлов.

Изучено: «МК-00007716-Тумба для моделей» (11.7МБ, 379 узлов, 234 меша),
метаданные «Стойка охранника» (63МБ), «СМФ.012.20 Переговорный» (62.8МБ).

## Как БАЗИС структурирует готовое изделие (glTF-иерархия)

```
корень
├── ящик_1..3          # сборочный узел: M1_Бок лев/пр, M1_Дно, M1_ЗС, M1_Фасад
│   ├── Саморез 3,5х16 …           # крепёж короба — отдельные узлы
│   ├── Гвоздь 1.6x25 …            # дно/ЗС ящика — гвозди
│   └── Замок для выдвижных…       # замок = узел с своими саморезами
├── дверь_пр.          # M1_Дв. + Петли накладные с доводчиком (узел из 2 петель:
│   │                  #   чашка+планка+саморезы) + Замок + Ручка + Заглушки + Винты M4
├── корпус             # панели + конфирматы + эксцентрики + шканты +
│                      #   полкодержатели + направляющие + опоры
└── Размер             # узлы размерных линий прямо в модели
```

Выводы для нас: сборочные узлы (ящик/дверь/корпус) — правильная группировка
для exploded view и спецификации; фурнитура-узел (петля, замок) включает свой
крепёж; размерные линии — часть сцены.

| Шкант 8×30 (S=16) | 18 | позиционирование стыков (в паре с minifix) |
| Гвоздь 1.6×25 | 9+ | задник/дно ящиков |

## Паттерны размещения (мировые координаты из glTF)

- **Конфирматы: ПАРАМИ с шагом 64 мм** на стык, отступ пары от торца ~31;
  уровни пар повторяются по каждой полке/стойке (95/159, 339/403, 583/647).
- **Гвозди (задник/дно ящика): сетка** шаг ~118–122 мм по одной оси и
  ~244 мм по другой, отступ от края ~55–61. На дно ящика ~350×500 — 3×3=9.
- **Шканты: 2–3 на стык** с шагом ~244 (127/371/615), в паре с эксцентриками;
  отступ от торца 2–39.
- **Minifix**: эксцентрик (чашка Ø15) в пласти на ~34 от торца (шток 34),
  отступ от торца панели ~18; парами по 2 на стык (135/634 при глубине ~750).
- **Полкодержатели: 4 на полку**, отступ от переднего/заднего края ~110–115
  (у нас 37 — МАЛО, реальная тумба использует больший отступ).
- **Опоры: 6 шт** при ширине ≥1000 (4 угла + 2 посередине).
- Саморез 3.5×16: Ø головки 7, длина 16.5; конфирмат: Ø8×52 (под сверло 7);
  шкант Ø8×32; minifix-шток длина 34.

## Что берём в конвейер (gap-анализ hardware.py)

Уже есть: ручки (2 винта М4), петли (чашка Ø35+планка), полкодержатели
(4/полку, но отступ 37 → поправить на ~110 от краёв... проверить по глубине),
конфирматы дно/крышка↔боковины (2/стык), винты направляющих (3/сторону).

Не хватает (реализация — AKD-136/137):
1. **Гвозди задника**: сетка по периметру + по внутренним стойкам/полкам,
   шаг ≤250, отступ ~10 от кромки ДВП (покрытие всей площади).
2. **Саморезы короба ящика**: бока↔дно/ЗС (2–3 на стык), фасад↔короб (4).
3. **BOM крепежа с количеством** (сейчас крепёж не попадает в спецификацию) +
   привязка к группе «Крепёж» производственной базы (313 позиций).
4. **Режим minifix**: скрытый крепёж корпуса — эксцентрик Ø15 (пласть, 34 от
   торца) + шток (торец) + шкант 8×30 рядом; выбор `carcass_fastener:
   "confirmat"|"minifix"` в ParamSpec.
5. Пары конфирматов с шагом 64 для широких стыков (сейчас отступы 50/50).
6. Замки (опция), заглушки на конфирматы (BOM-позиция).
7. Сборочные узлы ящик/дверь/корпус в экспорте (exploded, спецификация).
